# Orbit — Graduate Portfolio Prototype

A static, fictional 2040 graduate portfolio prototype for the university assessment.

## Run locally
1. Download or clone this folder.
2. Open `index.html` in a browser.

No installation, build step, server, API key, or external dependency is required.

## Run from GitHub
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js`, and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Customise the demo
- Edit the fictional graduate's name, subject, interests, quote and stats near the top of `app.js`, in the `profile` object.
- Edit the page text in the `pages` object in `app.js`.
- Change colours, spacing and layout in `styles.css`.

This is a front-end prototype using fictional sample data. It does not connect to a real AI model, save user data, or provide real account/privacy controls.
